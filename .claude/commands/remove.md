You are removing one entry from the Reading Room catalogue. This deletes the paper's source-of-truth files and its generated pages, then rebuilds. Work **interactively**; do **not** use the Anthropic API or `claude -p`.

## Input
`$ARGUMENTS` = a paper id (arXiv id or report slug), optionally `--approve`.

1. Normalize the id (lowercase, drop any `arXiv:` prefix and any `vN` suffix; slashes → `-`).
2. Confirm `reports/<id>/digest.json` exists. If not, list the ids under `reports/` and stop — there is nothing to remove (suggest the closest match if one is obvious).

## What gets removed
Collect the paths that actually exist, so the user sees precisely what will go:
- `reports/<id>/` — the digest, `notes.md`, and anything else in the folder (the source of truth).
- `papers/<id>.pdf` — the downloaded PDF, if present (gitignored).
- `.cache/<id>.txt` — any extracted text, if present (gitignored).
- `docs/papers/<id>/` — the generated report page. `build.py` only writes pages; it does **not** delete stale ones, so this directory must be removed explicitly (the rest of `docs/` is regenerated by the rebuild).

Also scan for **dependents** and report them — do **not** delete these unless the user asks:
- **Comparisons**: any `compares/<slug>/compare.json` whose `papers` array includes `<id>`. A comparison that references a deleted paper renders with a gap, so list each one and offer to remove its `compares/<slug>/` + `docs/compare/<slug>/` as well, or leave it.
- **Citations**: other digests whose `cites` include `<id>`. Note that the paper may reappear as a ghost node / reading-queue item once ≥2 of your papers cite it; the user can `/explain-paper` it again later or dismiss it on the graph.

## Confirm, then delete
Removal is **destructive and irreversible** (this is a delete-safety check, **not** the authoring Gate the other commands use). List the exact paths above plus any dependents, then delete once the user confirms. If `--approve` was passed, skip the confirmation and delete straight away.

Delete only the collected paths — remove the specific `reports/<id>/`, `papers/<id>.pdf`, `.cache/<id>.txt`, and `docs/papers/<id>/` you listed (and any comparison directories the user approved). Never use a broader glob or touch anything you did not list.

## Then rebuild and report back
Run `python verify.py --build` (rebuilds `docs/` from what remains and runs QA). Fix any `✗` failures. Confirm the paper is gone from `docs/index.html`, the library, and the graph, and report exactly what was deleted (and any comparisons / citations affected).
