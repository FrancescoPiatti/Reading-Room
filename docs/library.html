Browser reading state only (JSON)

Your reading status, priority stars, custom tags / collections, dismissed graph nodes, and theme live in this browser. Export them to a small JSON file to move them to another browser or device, or as a backup.

In the app they are also saved to user/reading-state.json as you go, so they survive a new browser, a different port, and a restore — this export is for moving them somewhere the app isn’t.

Your analysed papers, comparisons and discussions are files on disk. The full zip backup — and restore — lives in the Reading Room app (avatar menu → Back up); from an assistant, /backup export writes the same zip.
